## 项目概述

Claude Code 是 Anthropic 官方的 CLI 工具，用于在终端中与 Claude AI 进行交互式软件工程协作。这是一个包含 **1902 个源文件** 的大型 TypeScript/React 项目，核心技术栈包括：

- **语言**：TypeScript + TSX (React)
- **终端 UI**：自定义 Ink 渲染器（基于 react-reconciler + Yoga 布局引擎）
- **CLI 框架**：Commander.js
- **Schema 验证**：Zod
- **API 通信**：Anthropic SDK（支持多提供商）
- **扩展协议**：MCP (Model Context Protocol)
