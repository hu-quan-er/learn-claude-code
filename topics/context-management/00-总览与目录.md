# Claude Code 上下文管理机制分析

> 源码版本：claude-code 2.1.88
> 分析日期：2026-04-08

---

## 项目说明

本目录是对 Claude Code 上下文管理子系统的专题深度分析，聚焦于系统提示构建、消息处理流水线、上下文压缩策略、提示缓存优化、skill/tool 上下文保留等核心机制。

基于 `claude-code-2.1.88.tgz` 解包后的 1,902 个源文件（TypeScript）进行逆向分析。

## 关键数值速查

| 参数 | 值 | 说明 |
|------|------|------|
| 默认上下文窗口 | 200K tokens | 支持 1M（Sonnet 4.x / Opus 4.6） |
| 自动压缩缓冲 | 13,000 tokens | 有效窗口减去此值为触发阈值 |
| 压缩摘要预留 | 20,000 tokens | 全量压缩的输出 Token 预留 |
| 阻塞限制缓冲 | 3,000 tokens | 距有效窗口最近时的硬限制 |
| 断路器上限 | 3 次 | 连续自动压缩失败后停止 |
| 工具结果持久化 | 50K 字符 | 超出后写入磁盘 |
| 每消息预算 | 200K 字符 | 聚合工具结果上限 |
| 技能恢复预算 | 25K tokens | compact 后 `invoked_skills` 总预算 |
| 单技能恢复预算 | 5K tokens | compact 后每个 skill 内容截断 |
| 预览大小 | 2KB | 持久化结果的内联预览 |
| 缓存中断阈值 | 5% + 2000 tokens | cache_read 下降检测 |
| 默认缓存 TTL | 5 分钟 | 扩展 TTL 为 1 小时 |
| 媒体项上限 | 100 | 每请求 images + documents |
| 粗估比率 | 4 bytes/token | JSON 为 2 bytes/token |
| Git status 截断 | 2,000 字符 | 系统上下文中的 Git 状态 |
