# 00 - 总览与源码地图

## 两套实现

Claude Code 2.1.88 中，“todolist”实际上有两套实现：

| 通道 | 工具 | 默认使用场景 | 主状态 |
|------|------|--------------|--------|
| V1 | `TodoWrite` | 非交互式、SDK、远程任务日志 | `AppState.todos` |
| V2 | `TaskCreate` / `TaskUpdate` / `TaskGet` / `TaskList` | 交互式 CLI | `~/.claude/tasks/{taskListId}` |

分流函数在 `src/utils/tasks.ts`：

```typescript
export function isTodoV2Enabled(): boolean {
  if (isEnvTruthy(process.env.CLAUDE_CODE_ENABLE_TASKS)) {
    return true
  }
  return !getIsNonInteractiveSession()
}
```

这带来三个直接结果：

- 交互式 REPL 默认走 V2。
- 非交互式 / SDK 默认走 V1。
- `CLAUDE_CODE_ENABLE_TASKS=1` 可以强制 V2。

| `src/utils/attachments.ts` | 长时间未使用 TodoWrite 时生成 `todo_reminder` 附件 |
| `src/utils/messages.ts` | 将 `todo_reminder` 转成隐藏的 meta reminder 消息 |

### 工具传递与执行链路

| 文件 | 职责 |
|------|------|
| `src/tools.ts` | 基础工具集合注册，包含 `TodoWriteTool`，并在 V2 启用时追加 `Task*` 工具 |
| `src/utils/api.ts` | `toolToAPISchema()` 将本地 `Tool` 转为 Anthropic Messages API 的 `tools` schema |
| `src/services/api/claude.ts` | 构建 API 请求，把 `tools: allTools` 和 `tool_choice` 发给模型 |
| `src/query.ts` | 接收流式 assistant message，提取 `tool_use` block 并交给工具执行器 |
| `src/services/tools/StreamingToolExecutor.ts` | 流式场景下排队、并发调度和校验工具调用 |
| `src/services/tools/toolExecution.ts` | Zod 校验、权限检查、调用 `tool.call()`、生成 `tool_result` |
| `src/tools/ToolSearchTool/prompt.ts` | 动态工具加载场景下判断 `shouldDefer` 工具，并格式化 `<available-deferred-tools>` |
| `src/tools/{TodoWrite,TaskCreate,TaskUpdate,TaskGet,TaskList}Tool/prompt.ts` | 每个工具的 `PROMPT` 常量 / `getPrompt()` 函数，最终经 `tool.prompt()` 进入 API 请求的 `tools[].description` |

## 一张总图

```text
用户输入
  → query 构建 system prompt 和 tools schema
  → Anthropic Messages API
  → 模型选择输出 text 或 tool_use
  → query 捕获 assistant tool_use
  → StreamingToolExecutor / toolExecution
  → TodoWrite 写 AppState，或 Task* 写 ~/.claude/tasks
  → runtime 生成 user/tool_result message
  → 下一轮请求把 tool_result 和历史消息再发给模型
```

## 名词对照

| 名词 | 含义 |
|------|------|
| `Tool` | Claude Code 内部工具对象，包含 `name`、`prompt`、`inputSchema`、`call` 等字段 |
| `tools` API 字段 | 发给模型的工具 schema 数组，每项包含 `name`、`description`、`input_schema` |
| `tool_use` | 模型在 assistant message 中返回的工具调用 block |
| `tool_result` | Claude Code 执行工具后，以 user message block 形式回填给模型的结果 |
| `TodoList` | V1 的 `TodoItem[]` 类型，不等于 V2 的文件态 task list |
| `Task` | V2 任务对象，有稳定 ID、状态、owner、依赖和 metadata |
